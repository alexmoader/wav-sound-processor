# WAV-процессор на C++

Я написал консольную утилиту для обработки WAV. Она читает монофонический PCM 16 бит, 44,1 кГц, применяет фильтры в заданном порядке и сохраняет результат в WAV. Можно изменить громкость, нормализовать сигнал, добавить паузу, растянуть сигнал или сгладить его низкочастотным фильтром. Есть генераторы синусоиды, AM и FM.

## Сборка и запуск

```sh
cmake -S . -B build
cmake --build build
./build/sound_processor -o tone.wav -f generator sin 440 1000
./build/sound_processor -i tone.wav -o result.wav -f ampl 0.8 -f lowpass 5
ctest --test-dir build --output-on-failure
```

Для сборки нужны CMake 3.20+ и компилятор с поддержкой C++17. CMake использует установленный Catch2 3 или скачивает его при включённых тестах. Для сборки только утилиты укажи `-DBUILD_TESTING=OFF`. Запуск без аргументов выводит список фильтров и форматы команд.
